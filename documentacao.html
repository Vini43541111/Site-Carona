1. Descrição do Sistema

O CaronaUni é uma plataforma web de caronas universitárias desenvolvida para conectar, de forma simples e segura, estudantes da Unoesc (Universidade do Oeste de Santa Catarina) que oferecem vagas em seus veículos com estudantes que precisam de deslocamento até o campus.

A plataforma resolve problemas recorrentes na comunidade acadêmica: a dificuldade de encontrar caronas confiáveis, a ausência de um processo organizado para solicitar e confirmar vagas, e a falta de histórico e avaliação para aumentar a confiança entre usuários.

🎯 Propósito
  • Facilitar o deslocamento diário da comunidade acadêmica
  • Reduzir custos individuais de transporte
  • Diminuir o número de veículos em circulação
  • Promover sustentabilidade no campus
⚙️ Como funciona
  1. Usuário faz login via SSO Unoesc (mock)
  2. Motorista cria uma carona com rota e horário
  3. Passageiro busca e solicita uma vaga
  4. Motorista aceita ou recusa a solicitação
  5. Após a carona, ambos se avaliam
2. Escopo do Sistema
✅ Incluso (O que o sistema tem)
  • Login e identificação de usuário (SSO mock)
  • Cadastro de carona com rota, horário e vagas
  • Mapa interativo para definição de trajeto
  • Busca de caronas disponíveis com filtros
  • Solicitação de vaga pelo passageiro
  • Aceite ou recusa da solicitação pelo motorista
  • Registro de avaliação pós-carona
  • Histórico de caronas realizadas
  • Gerenciamento de perfil e veículos
  • Sistema de notificações (simulado)
  • Caronas recorrentes por dia da semana
❌ Fora de Escopo
  • Pagamento integrado
  • App mobile nativo completo
  • Otimização avançada de rotas (Waze/Maps)
  • Integração real com SSO da Unoesc
  • Chat em tempo real (WebSocket)
  • Backend e banco de dados reais
  • Notificações push nativas
📌 Modalidade: Continuação evolutiva do projeto do semestre anterior. Foco em documentação evolutiva, modelo ER e protótipo funcional navegável. Modelo de execução: Ágil Incremental (iterativo).

4. Arquitetura do Sistema

O sistema segue uma arquitetura em camadas com separação entre Frontend, Backend e Dados, conforme o diagrama de componentes definido na modelagem.

🌐 Frontend (Interface Web)

Protótipo em HTML5, CSS3 e JavaScript puro. Responsivo e navegável. Mapa interativo via Leaflet.js + OpenStreetMap.

HTML/CSS/JS Leaflet.js

⚙️ Backend (API REST)

Camada de serviços responsável pela lógica de negócio: autenticação, caronas, solicitações e avaliações.

Node.js / Python REST API

🗄 Banco de Dados

Armazenamento relacional das entidades: Usuário, Carona, Solicitação, Avaliação e Mensagem.

PostgreSQL / MySQL

🔐 SSO Institucional

Integração com o sistema de login da Unoesc para autenticação e validação de matrícula ativa.

Mock no protótipo
Fluxo de dados: Interface Web → HTTPS → API REST → Serviços (Carona / Usuário / Mensagem) → Banco de Dados
Autenticação: Interface Web → SSO Unoesc → Token JWT → API REST
